# Portfolio content — edit here

All text, links, and lists for the site live in this folder. You usually **do not** need to open `.html` or `.ts` page files.

| File | What you change |
|------|------------------|
| `profile.data.ts` | Your name, photo paths, years of experience, resume link, social URLs |
| `home.data.ts` | Hero headline, badge, tech pills, button labels |
| `about.data.ts` | About text, skill boxes, extra links |
| `projects.data.ts` | Project list (add/remove/edit projects) |

After saving a file, the dev server reloads automatically.
